Русский текстовый перевод **DEADLINE: Afterlife Processing Demo** для одной проверенной Windows-сборки на Unity 6000.3.5f2.

**Скачайте `DEADLINE-RU-v1.0.0-windows-x64.zip`, полностью распакуйте и запустите `INSTALL.cmd`.** Установщик находит игру в Steam либо позволяет указать её папку. Переносимый Python уже включён; интернет при установке не нужен.

- Меню, настройки, руководство, истории душ, директивы, записки, отчёты, договоры и магазин.
- Поддержка кириллицы, в том числе «ё»; подгонка текстовых подписей.
- Проверка версии по SHA-256, резервная копия перед установкой, повторный запуск без изменений.
- Откат: `RESTORE.cmd`. Проверка: `CHECK.cmd`.

В архиве нет полных файлов игры и шрифтов Windows. Патч применяется к локальной копии игры; шрифты берутся с компьютера игрока. Сохранения не изменяются. Озвучка и текст, запечённый в отдельных изображениях, остаются оригинальными.

Архивы **Source code** предназначены для разработки. Подробности и совместимость — в README. Результаты локальных проверок установщика — в `tests/VALIDATION.json`.
