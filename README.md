# Русский перевод DEADLINE: Afterlife Processing Demo

Неофициальная текстовая русификация демоверсии **DEADLINE: Afterlife Processing** для Windows x64.

Переведены меню и настройки, руководство Оператора, истории душ, директивы, служебные записки, отчёты, договоры, магазин и текстовые надписи сцены. Добавлена кириллица. Для четырёх рукописных записок включён предусмотренный игрой вариант с набранным текстом. Озвучка, логотип и текст, запечённый в остальных изображениях, не переводились.

## Установка

1. Скачайте **DEADLINE-RU-v1.0.0-windows-x64.zip** из [Releases](https://github.com/shersh/deadline-afterlife-demo-ru/releases/latest), затем полностью распакуйте архив.
2. Закройте игру и запустите `INSTALL.cmd`.
3. Установщик попробует найти игру в библиотеках Steam. Если не найдёт, укажите папку, в которой находится `DEADLINE.exe`. Можно также перетащить эту папку на `INSTALL.cmd`.
4. Запускайте игру через Steam. Отдельного выбора языка нет: перевод заменяет английские тексты.

Готовый ZIP работает без установленного Python, SDK и загрузки зависимостей из интернета. Нужны Windows 10/11 x64, стандартный .NET Framework 4.x и установленная совместимая демоверсия. Патчу требуется место для резервной копии и временной сборки — ориентировочно 500 МБ.

Архивы **Source code** — исходники для разработки, без переносимого Python и собранного обработчика сборки.

## Откат и повторная установка

Закройте игру и запустите `RESTORE.cmd`. Можно передать папку игры перетаскиванием, как при установке. Оригиналы сохраняются рядом с игрой в `DEADLINE_RU_Backup`; не удаляйте эту папку до отката. Сохранения игрока не изменяются.

`CHECK.cmd` проверяет совместимость и состояние установки. Повторный запуск установщика после успешной установки ничего не переписывает. Если файлы изменились после установки, откат остановится, чтобы не затереть эти изменения.

Если у вас уже стоит ранний локальный перевод с папкой `_RussianLocalization`, сначала запустите её `RestoreOriginal.cmd`, а затем новый установщик.

## Совместимость

Версия патча: **1.0.0**. Поддерживается одна проверенная Windows-сборка демоверсии на Unity **6000.3.5f2**. Точные SHA-256 исходных 11 файлов приведены в [payload/manifest.json](payload/manifest.json). Дата по имени файла не используется для определения версии.

Установщик сначала проверяет все исходные файлы, готовит перевод во временной папке и сохраняет оригиналы. При несовместимой версии установка не начинается. При ошибке замены предусмотрен автоматический откат. После обновления игры в Steam старый патч может перестать подходить; проверка целостности в Steam убирает локальные изменения.

## Что находится в пакете

- 364 изменения текстовых полей CSV и 31 дополнительный ключ интерфейса.
- Изменения 162 объектов Unity: подписи, бланки, настройки кириллицы и записок.
- 255 переводов встроенных строк. Внутренние коды вердиктов и условия прохождения сохранены.
- 107 точек вывода текста переводят названия вердиктов при отображении, сохраняя исходные значения в игровых данных.

В репозитории и релизе **нет** полных файлов игры, её исходного кода, оригинальных DLL/ассетов или файлов шрифтов Windows. Патч содержит перевод и небольшие изменения относительно установленной игры. Consolas, Courier New и Arial читаются из локальной папки шрифтов Windows на компьютере игрока.

## Проверка

На исходной локализации проверены запуск игры, полный русский алфавит в девяти шрифтах TextMesh Pro и пяти загруженных обычных шрифтах, а также вёрстка начального и финального договоров. Полное прохождение всех пяти смен не выполнялось.

Переносимый установщик проверяется отдельно: установка на копию оригиналов, сравнение содержимого изменённых объектов, повторная установка, точный откат, отказ на изменённых файлах и восстановление после ошибки замены. Для публичных тестов оригинальные файлы игры не требуются; интеграционные проверки используют локальную копию владельца игры.

## Для разработки

Установщик [patch.py](patch.py) использует только стандартную библиотеку Python 3.10+. Обработчик .NET-сборки — [src/AssemblyPatcher.cs](src/AssemblyPatcher.cs), библиотека Mono.Cecil 0.11.6. Готовый переносимый ZIP собирается на Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build_release.ps1
```

Сборка скачивает закреплённые пакеты Python и Mono.Cecil с официальных серверов, проверяет SHA-256, компилирует собственный обработчик системным компилятором .NET Framework и создаёт ZIP в `dist/`. Ни Python, ни Mono.Cecil не устанавливаются в систему.

```powershell
py -3 -m unittest discover -s tests -v
py -3 patch.py check --game "D:\SteamLibrary\steamapps\common\DEADLINE Afterlife Processing Demo"
```

`tools/export_payload.py` — инструмент разработчика, который строит данные патча по двум локальным копиям файлов: оригиналу и проверенной переведённой версии. Для него нужен UnityPy 1.25.4; игрокам он не нужен. Не добавляйте сами файлы игры, локальные резервные копии или системные шрифты в Git.
